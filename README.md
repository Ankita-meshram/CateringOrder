## Catering Order System

Name: Ankita Meshram
Roll Number: MCA36
Task Number: 36

## Technologies Used

- HTML, CSS, JavaScript
- JSP and JDBC
- MySQL

## Description

This project manages catering orders by storing customer name, event, number of plates, and rate per plate. JavaScript validates that plates are at least 10. JSP and JDBC save and display order records from MySQL, including the total bill.
